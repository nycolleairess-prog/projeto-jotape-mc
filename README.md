# Projeto Jotapê MC

## Sobre o projeto

Este projeto foi desenvolvido como atividade da disciplina de HTML.

O site apresenta informações sobre o rapper e MC de batalha Jotapê, mostrando um pouco da sua história, carreira, títulos, músicas e sua trajetória.

## Páginas

O projeto possui 4 páginas:

- Início
- Carreira
- Músicas
- Contato

Todas as páginas possuem um menu para facilitar a navegação.

## Recursos utilizados

Durante o desenvolvimento foram utilizados recursos de HTML, como:

- Tags semânticas
- Imagens
- Áudio
- Vídeo
- Tabela
- Formulário
- Datalist
- Details e Summary
- Figure e Figcaption
- Progress e Meter
- Abbr
- Blockquote
- Mark
- Del e Ins

## Organização das pastas

- `html/` - páginas do site
- `img/` - imagens utilizadas
- `audio/` - arquivo de áudio
- `video/` - arquivo de vídeo

## Desenvolvimento

O projeto foi desenvolvido utilizando HTML, sem CSS ou JavaScript.

## Tema

O tema escolhido foi Jotapê MC, destacando principalmente sua trajetória nas batalhas de rima e sua carreira musical.
